# Web Services (VERSÃO - PT)

Projeto desenvolvido com o objetivo de praticar o desenvolvimento de **Web Services utilizando Spring Boot**, explorando a configuração do framework e a utilização de diferentes dependências para construção de aplicações Java.

## Tecnologias utilizadas

* Java
* Spring Boot
* Maven

## Objetivos

Este projeto foi desenvolvido como parte dos estudos em desenvolvimento backend, com foco na prática dos seguintes conceitos:

* Desenvolvimento de aplicações com Spring Boot;
* Criação e organização de projetos Java;
* Utilização e gerenciamento de dependências com Maven;
* Estruturação de uma aplicação backend;
* Desenvolvimento de Web Services.

## Estrutura do projeto

```text
Web-Services/
├── .mvn/
├── src/
├── .gitattributes
├── .gitignore
├── mvnw
├── mvnw.cmd
└── pom.xml
```

## Como executar

### Pré-requisitos

* Java instalado
* Maven instalado (opcional, pois o projeto possui Maven Wrapper)

### Executando com Maven Wrapper

No Windows:

```bash
./mvnw.cmd spring-boot:run
```

No Linux/macOS:

```bash
./mvnw spring-boot:run
```

Também é possível executar o projeto diretamente pela IDE de sua preferência.

## Sobre o projeto

O **Web-Services** é um projeto de estudo desenvolvido para colocar em prática conceitos relacionados ao desenvolvimento backend com **Java e Spring Boot**.

O projeto faz parte do processo de aprendizado e experimentação com o ecossistema Spring, servindo como base para a evolução dos conhecimentos em desenvolvimento de APIs e Web Services.
